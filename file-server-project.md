# Linux Department File Server Project

## Objective

Configured a Linux-based company file server structurer with department-level access controls 

## Environment
-Ubuntu Desktop 
-Oracle VirtualBox

## users created
-technician
-marketing
-manager

## Groups Created 
-IT
-Marketing
-Management


## Implementation 
-Created depatment folders
-Assigned folder ownership using chown
-Configured permisiions using chmod
-tested user access restrictions

## Security Result
users can access only the folders assigned to their department.
